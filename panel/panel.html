Match your own typing

Two short phases, because they measure different things. Copying a passage measures your fingers — the intended text is known, so every mistake is countable. Writing your own answer measures how you pause and rewrite, which copying can never show, because when the words are given to you there is nothing to think about.

How to use it

  1. Put your text in the box on the Write tab.
  2. Pick a style and whether they're composing or copying.
  3. Press Preview here to watch it without touching any page.
  4. To type for real: click into the text box on the target page, pick that tab under Type into, and press Type into page.

Press Stop, hit Escape on the target page, or use the Stop button on the page itself to halt mid-way.

The quicker way

For most jobs you never need this tab. Click the Pacetyper toolbar button while you are already on the page you want filled and a small panel opens over it with the same text box and settings. Your draft and settings are shared between the two, so whatever you type here appears there.

Where this works

Ordinary web text boxes — comment fields, forms, webmail bodies — rich-text editors, and canvas-rendered editors such as Google Docs. Ordinary boxes get the browser's own editing command, so the page receives the same trusted input events a real keypress produces.

Google Docs has no editable area to type into: it paints to a canvas and reads keys from a hidden frame. Pacetyper tries several channels there and keeps whichever one the editor honours, checking each attempt against the caret — the one thing that moves when an edit really lands. If none of them work, it stops and says so rather than pretending.

Firefox's own pages (about:*, the add-ons site) block every extension and cannot be typed into by anything.

If a page ignores it

Click directly inside the text box first so the cursor is visibly in it. If Pacetyper cannot find a box it will ask you to click one, and the page shows its own progress chip while typing — so you never have to come back here to find out what happened.

Check it still works

Run the engine self-check — determinism, 800 fuzz plans, calibration accuracy, keyboard timing order, deadline fitting, and a round trip that trains on the engine's own output. Takes a second or two; everything should say PASS.

What the settings mean

Composing vs copying
The same person composes at roughly 60% of the rate they copy, and nearly all the difference is pauses — between words, at commas, and especially at sentence ends.
Mistakes
Errors land on keys next to the intended one, cluster where your fingers are already awkward, and get noticed a few characters later — then backspaced and retyped.
Fix every mistake
Guarantees the final text matches yours exactly. Without it, a few slip through the way they really do.
Breaks
For essay-length work. Break time is excluded from the speed reading, because a break is not slow typing.
